# Etsy Listing Auditor — LITE (Free)

A free Claude skill file that checks a draft Etsy listing against Etsy's published compliance rules before you publish — tags, title, pricing and sales, AI disclosure, and digital-delivery rules.

Every rule comes from Etsy's own Seller Handbook and Etsy's announced policy updates through October 2026, including the AI disclosure rules (October 22, 2026) and the Off-Platform Policy rule on QR codes (October 5, 2026).

## What it does

Give Claude your draft listing — title, tags, description, price and sale dates, delivery files — and it returns one line per check: PASS, or FAIL with the offending text quoted and what to change.

It catches the mistakes that actually get listings in trouble:

- Tags over the 20-character limit, or not exactly 13 tags
- Keyword-stuffed titles that don't read like a person wrote them
- Seller-made "Bestseller" / "Star Seller" badges (prohibited, even if you earned the status)
- Undated or perpetual sales, and fake urgency on them
- A missing AI disclosure sentence when AI helped make the product or the listing
- Spreadsheets delivered as .xlsx instead of inside a .zip, and QR codes in delivered files

## How to use it

1. Download `etsy-listing-auditor-LITE-free.md`.
2. In Claude, start a chat and attach the file (or paste its contents), then paste your draft listing.
3. Read the checklist result and fix what fails before you publish.

No coding, no terminal. Works in Claude chat, a Claude Project, or a Claude Code skills folder.

## Honest limits

This checklist checks a draft against published rules and sound listing practice. It does not guarantee sales, search ranking, or traffic, and it cannot predict Etsy's enforcement decisions. Etsy changes its rules — where this file and the current Seller Handbook disagree, the Handbook wins. Final responsibility for a listing stays with the seller.
